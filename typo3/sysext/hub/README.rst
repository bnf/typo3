===========================
TYPO3 extension `hub`
===========================

This extension handles incoming webhooks to TYPO3. It also provides
a corresponding backend module to manage app records in the TYPO3
backend (`System > Integrations > Hub`).

:Repository:  https://github.com/typo3/typo3
:Issues:      https://forge.typo3.org/
:Read online: https://docs.typo3.org/c/typo3/cms-hub/main/en-us/
:TER:         https://extensions.typo3.org/extension/hub/
